# Smart Online Quiz Platform 🎯

A full-stack web-based quiz application designed to simulate real-world online assessments. 
Built using Python and Flask, the platform focuses on clean architecture, user experience, 
and scalable backend logic.

---

## 🚀 Features
- Dynamic quiz generation from database
- Timer-based assessment with auto-submit
- Client-side validation to ensure all questions are answered
- Automatic score calculation and result analytics
- Clean, modern UI with CSS gradients and responsive design

---

## 🛠️ Tech Stack
- Backend: Python, Flask
- Frontend: HTML, CSS, JavaScript
- Database: SQLite
- Tools: VS Code, Git
